# Sample images

Four test-set images per class from the NIH/NLM malaria cell image dataset, courtesy of the U.S. National Library of Medicine. File names are unchanged from the NIH download.

The full dataset (27,558 images) is available from the [NLM malaria datasheet page](https://lhncbc.nlm.nih.gov/LHC-research/LHC-projects/image-processing/malaria-datasheet.html). See the main README for the download steps and the dataset reference.
